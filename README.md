# Dart_Rack_Control

初步实现镖架控制功能的 STM32 裸机工程。

当前通过 UART7 接收指令，控制 Yaw、3508 滑台电机、2006 扳机位置以及发射流程。工程基于 STM32CubeMX / Keil MDK-ARM，CAN1 用于电机通信。

## UART7 指令

```text
0\r\n              调试信息开关
1\r\n              LED Toggle
2 <位置>\r\n     3508 拉动滑台
3 <位置>\r\n     扳机锁紧后 3508 返回
4\r\n              执行发射
5 <位置>\r\n     Yaw 调整
6 <位置>\r\n     2006 位置调整
7\r\n              2006 归零
```

3508 位置范围为 `-100000 ~ 1070000`，Yaw 位置范围为 `10000 ~ 110000`。详细控制状态和参数见 `Core/Src/main.c`。
