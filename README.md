# Dart_Rack_Control

初步实现镖架控制功能的 STM32 裸机工程。

当前通过 UART7 接收串口屏按钮帧，控制 3508 滑台、2006 扳机位置以及发射流程。工程基于 STM32CubeMX / Keil MDK-ARM，CAN1 用于电机通信；Yaw 控制代码保留但串口屏没有对应按钮。

## UART7 指令

串口屏应使用 **115200、8N1**，每帧为**一个二进制命令字节**后跟 `0D 0A`；以下均为十六进制字节，非 ASCII 字符串。旧电脑端 ASCII 指令不再解析。

| 发送帧 | 动作 |
| --- | --- |
| `00 0D 0A` | 同时启动 2006 和两台 3508 寻零；三台均成功后才能选档 |
| `10 0D 0A` | 2006 目标 `36500000`，选择 3508 装载目标 `760000` |
| `11 0D 0A` | 2006 目标 `24500000`，选择 3508 装载目标 `920000` |
| `12 0D 0A` | 2006 目标 `12500000`，选择 3508 装载目标 `1020000` |
| `13 0D 0A` | 2006 目标 `500000`，选择 3508 装载目标 `1060000` |
| `01 0D 0A` | 2006 到位后拉动弹簧；3 秒后锁紧，回程至 `5000` |
| `03 0D 0A` | 扣动扳机（保留旧状态放行条件） |
| `20 0D 0A` | 切换 LED |

3508 的位置相对于各自寻得的零点。寻零时以 `-1000 RPM`、电流命令上限 `3200` 运行；屏蔽最初 300 ms 后，每台分别要求 C620 反馈电流绝对值至少 `2500`、速度绝对值至多 `50 RPM` 连续 200 ms，3508 超时为 10 秒。2006 使用原有寻零策略。任一电机寻零失败将终止整个初始化；实际运动效果尚未进行硬件验证。详细状态和参数以 [控制源码](Core/Src/main.c) 为准。

工程入口为 [MDK-ARM/Dart_Rack_Control_v1t.uvprojx](MDK-ARM/Dart_Rack_Control_v1t.uvprojx)，外设配置为 [Dart_Rack_Control_v1t.ioc](Dart_Rack_Control_v1t.ioc)。可在相应工具中打开工程；构建、烧录及硬件运行条件尚待核实，不将上方指令表视为硬件操作授权。操作前查阅 [操作手册](docs/context/RUNBOOK.md) 和 [风险](docs/context/RISKS.md)。
