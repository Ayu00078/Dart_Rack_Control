# 风险与验证缺口

- **机构运动风险**：现有 [README 指令](../../README.md#uart7-指令) 包含归零、运动和发射；执行前须确认现场安全与授权，按 [操作手册](RUNBOOK.md) 核对设备和机械限位。实际防护方案待核实。
- **验证缺口**：[Keil 工程配置](../../MDK-ARM/Dart_Rack_Control_v1t.uvprojx) 只证明存在构建配置；本次未验证工具安装、构建、烧录或硬件效果。应分别留存当次证据，不将配置或旧结果视为通过。
- **保留的发射放行例外**：按用户确认，[源码](../../Core/Src/main.c) 中寻零进行中拒绝发射，但初始化失败进入 `FAULT` 后仍允许按旧逻辑发射；回程中或其他 `FAULT` 状态也允许发射。`FAULT` 不代表机构处于安全位置，现场必须另行确保安全。
- **定时装载与硬件缺口**：3 秒后在双 3508 反馈在线时直接锁紧，不证明已到装载位置；反馈失联终止自动流程。寻零目标方向、`3200` 上限及反馈阈值 `2500` 是否适合实际机械与电调，待受控硬件核实。

风险证据或状态变化时定点修订；此处不推断未核对的硬件故障。
